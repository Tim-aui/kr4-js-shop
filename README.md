# kr4-js-shop — интерактивный интернет-магазин видеокарт

## Контрольная работа №4

Тема: «JavaScript: интерактивность, DOM, события, формы и валидация».

Дисциплина: «Фронтенд и бэкенд разработка».

## Описание

Проект — интерактивная версия учебного интернет-магазина видеокарт «ПослеМайнинга».
За основу взят проект **КР №3** (`kr3-responsive-shop`) — адаптивная версия
HTML/CSS-магазина. Вёрстка и адаптивность сохранены, поверх неё добавлена
интерактивность на чистом JavaScript (ES6+) без jQuery и других библиотек.

## JavaScript-файлы

- `data.js` — массив товаров `products`.
- `main.js` — общая инициализация: функция `formatPrice()`, мобильное меню,
  сворачиваемая панель фильтров каталога.
- `catalog.js` — генерация карточек, поиск, фильтрация, сортировка, счётчик найденных
  товаров, пустое состояние, кнопки «В корзину».
- `cart.js` — корзина: добавление, изменение количества, удаление, очистка,
  расчёт суммы через `reduce`, промокод, сохранение в `localStorage`,
  счётчик товаров в меню.
- `modal.js` — открытие и закрытие модального окна заявки на главной.
- `validation.js` — базовая валидация формы заявки (на `order.html` и в модальном
  окне на главной), вывод ошибок и сообщений на страницу, имитация отправки.
- `product.js` — заполнение страницы товара данными из `data.js`, кнопка «В корзину».
- `success.js` — персональное сообщение на странице `success.html`.

Порядок подключения (все скрипты с `defer`): `data.js` → `main.js` → `cart.js` →
скрипт страницы. На каждой странице подключены только нужные файлы, а код
проверяет наличие элементов (`if (catalogGrid)`, `if (cartList)`, `if (orderForm)`),
поэтому на страницах без этих блоков ошибок в консоли нет.

## Массив товаров

В `js/data.js` — 10 товаров с одинаковой структурой:

```js
{
  id: 1,
  title: 'Видеокарта ASUS GeForce RTX 5080 ROG Astral OC Edition',
  category: 'top',
  price: 164990,
  isAvailable: true,
  image: 'asus-rtx-5080',
  sizes: [320, 500],
  badge: 'hit',
  description: '...',
  fullDescription: '...',
  chip: 'GeForce RTX 5080',
  memory: '16 ГБ GDDR7',
  interface: 'PCIe 5.0'
}
```

- обязательные свойства: `id`, `title`, `category`, `price`, `isAvailable`;
- дополнительные: `image` и `sizes` (имя файла и ширины для `srcset`), `badge`
  (`hit` / `new` / `discount` / `null`), описания и характеристики;
- `id` уникальны, цены записаны числами;
- категории `top`, `middle`, `budget` совпадают со значениями `option` в фильтре;
- два товара (`id: 7` и `id: 10`) имеют `isAvailable: false`.

## Реализованные функции

- генерация карточек каталога через JavaScript;
- поиск по названию товара;
- фильтрация по категории;
- сортировка по цене (по возрастанию / по убыванию) и по названию;
- вывод количества найденных товаров и пустое состояние;
- валидация формы заявки с выводом ошибок рядом с полями;
- сообщения об ошибке и об успешной подготовке заявки на странице, без `alert()`;
- корзина с сохранением в `localStorage`, расчётом суммы и промокодом;
- страница товара, собираемая из `data.js`.

## Генерация карточек

Функция `createProductCard(product)` в `catalog.js` создаёт карточку через
`document.createElement`: `article`, `img`, бейдж, `h3`, описание, наличие, цену,
ссылку «Подробнее» и кнопку «В корзину». Текст заполняется через `textContent`,
классы добавляются через `classList.add`, элементы собираются через `append`.

`renderCatalog()` находит контейнер `#catalog-grid` через `querySelector`, очищает его
(`textContent = ''`), проходит по отфильтрованному массиву и добавляет карточки.

## Поиск

Поле `#search-input`, событие `input`. Строка запроса приводится к нижнему регистру
и обрезается `trim()`, затем `products.filter()` оставляет товары, у которых
`title.toLowerCase().includes(query)`. Список обновляется при каждом вводе символа.

## Фильтрация

Список `#category-select`, событие `change`. Если выбрано `all`, показываются все
товары, иначе — только те, у которых `product.category === category`.
Поиск и фильтр работают вместе.

## Сортировка

Список `#sort-select`, событие `change`. Варианты: по умолчанию, по цене по возрастанию,
по цене по убыванию, по названию А–Я. Сортируется копия массива:

```js
const sortedProducts = [...result];
sortedProducts.sort((a, b) => a.price - b.price);
```

Исходный массив `products` не меняется. Для названий используется
`localeCompare(b.title, 'ru')`.

## Валидация формы

Форма `#order-form` на `order.html` (и такая же форма в модальном окне на главной).
Обработчик `submit` вызывает `event.preventDefault()` и функцию `validateOrderForm()`:

- имя — не короче 2 символов;
- e-mail — не пустой и соответствует `/^[^\s@]+@[^\s@]+\.[^\s@]+$/`;
- телефон — не пустой и в формате `+7 (900) 000-00-00`;
- тема заявки и товар — выбраны;
- согласие на обработку данных — отмечено.

Ошибки выводятся в элементы `.order-form__error` под полями, поле получает класс
`order-form__input--invalid` и `aria-invalid="true"`, фокус переводится на первое
неверное поле. Над кнопками выводится общее сообщение «Проверьте правильность
заполнения полей формы». После корректного заполнения выводится сообщение
«Спасибо, …! Ваша заявка подготовлена.»

## Безопасный вывод данных

- все данные товаров, данные формы (имя пользователя в сообщении) и данные из
  `localStorage` выводятся только через `textContent`;
- элементы создаются через `createElement` и добавляются через `append`;
- `innerHTML` в проекте не используется;
- inline-обработчики (`onclick`) в HTML не используются, все обработчики подключены
  через `addEventListener()`.

Проверка: если в название товара записать `<img src=x onerror=alert(1)>`, на странице
выводится текст, а не картинка.

## Самостоятельные доработки

- **Корзина** (`cart.html`, `cart.js`) — добавление товаров из каталога и со страницы
  товара, кнопки «+» / «−», удаление позиции, очистка корзины. Кнопки списка
  обрабатываются одним обработчиком через делегирование событий и `data-action` / `data-id`.
- **Расчёт суммы через `reduce`** — `getCartTotal()` считает сумму, `getCartCount()` —
  количество товаров.
- **localStorage** — корзина хранится под ключом `kr4-cart` и не пропадает при
  переходе между страницами и перезагрузке.
- **Промокод** — `STUDENT10` (скидка 10%) и `MINING20` (скидка 20%), выводятся скидка
  и итоговая сумма; неверный промокод даёт сообщение об ошибке.
- **Счётчик товаров** — в меню на всех страницах рядом с пунктом «Корзина».
- **Улучшенная карточка товара** — бейджи «Хит» / «Новинка» / «Скидка», статус
  наличия; у товаров не в наличии кнопка «В корзину» заблокирована. После добавления
  кнопка на 1,5 секунды меняется на «Добавлено».
- **Расширенное пустое состояние каталога** — пояснение и кнопка «Сбросить фильтры».
  Пустое состояние есть и у корзины (ссылка в каталог).
- **Имитация отправки формы** — кнопка блокируется и показывает «Отправка...»,
  через 1 секунду выводится сообщение об успехе, форма очищается. Ошибка поля
  убирается, как только пользователь его исправляет; кнопка «Очистить» убирает
  ошибки и сообщения.
- **Страница товара из `data.js`** — `product.html?id=N` заполняется данными массива,
  кнопка «Оформить заявку» подставляет товар в форму на `order.html`.

### Как проверить доработки

1. Открыть `catalog.html`, нажать «В корзину» у нескольких товаров — счётчик в меню
   увеличивается.
2. Открыть `cart.html`, поменять количество, удалить товар — сумма пересчитывается.
3. Ввести промокод `STUDENT10` — появляется скидка 10%; ввести `abc` — сообщение
   «Промокод не найден».
4. Перезагрузить страницу — корзина сохранилась.
5. В каталоге ввести `qwerty` — появляется пустое состояние, нажать «Сбросить фильтры».
6. На `order.html` отправить пустую форму — ошибки под полями; заполнить корректно —
   «Отправка...», затем сообщение об успехе.

## Проверка консоли

Страницы `index.html`, `catalog.html`, `product.html`, `cart.html`, `order.html`,
`contacts.html`, `success.html` проверены в DevTools → Console: ошибок нет.

## Локальный запуск

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000`.

Можно также открыть `index.html` двойным кликом — скрипты подключены обычными
тегами `<script>`, без модулей, поэтому работают и без сервера.
